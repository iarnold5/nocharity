Free MCP Internet Deployment Guide

How this application runs on the internet for $0 using Model Context Protocol (MCP)

1. What MCP Servers Are Used?

To achieve real-time news search and donation extraction on the internet with zero cost and zero paid API keys, this application implements a standard MCP Server architecture:

  • News Search MCP Tool (search_billionaire_news): Queries Google News RSS and open news endpoints with custom timeframe syntax (when:1y, when:30d). It requires $0, needs no subscription, and parses donation figures automatically with regex.
  • Parity Math MCP Tool (calculate_donation_parity): Computes percentage of net worth and maps it to tangible real-world equivalents for personal incomes.
  • Philanthropy Index MCP Tool (get_billionaires_list): Provides Forbes scores, verified tax filing records, and Giving Pledge status.

2. Running This MCP Server In AI Clients

You can register this MCP server in Claude Desktop or Antigravity by adding the included mcp_config.json to your config: 

{
  "mcpServers": {
    "billionaire-philanthropy": {
      "command": "node",
      "args": ["${path_to_repo}/mcp-server.js"]
    }
  }
}

3. How To Host It On The Internet For Free

You can deploy this full-stack app online completely free on several cloud platforms:

A. Render.com (Recommended Free Tier)

Push this folder to GitHub, create a free "Web Service" on Render, choose Node.js, and set build command to npm install and start command to node server.js. You get a free HTTPS domain.

B. Hugging Face Spaces (Free Docker/Node)

Create a free Space with Node.js / Docker. Free 24/7 web hosting without cold start restrictions.

C. GitHub Pages (Static Client-Side Mode)

The public/ folder contains an autonomous client-side fallback with the full dataset and live parity engine, so it can be hosted directly on GitHub Pages with zero servers!

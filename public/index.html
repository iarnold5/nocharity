Free MCP Architecture & Deployment

How this application runs for $0 on the internet

1. The Zero-Cost MCP News Engine

This app implements a standard Model Context Protocol (MCP) server in mcp-server.js that queries Google News RSS feeds with timeframe syntax (when:1y, when:30d). It requires zero API keys and costs $0.

2. Free Deployment to Render

You can deploy this directly from your GitHub repo (iarnold5/nocharity) to a free Render Web Service. Render runs npm install and npm start automatically at $0/month.

3. Direct Source Links

Every single donation displayed in the billionaire carousel links directly to the verified news article from AP News, Reuters, WSJ, Bloomberg, and the Chronicle of Philanthropy.

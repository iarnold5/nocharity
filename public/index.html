About NoCharity Satirical Premise • Public Data

NoCharity is an independent project built on a comedic premise inspired by Gianmarco Soresi's joke. It is intended to be light-hearted and satirical. We use publicly available information and attempt to present it as accurately as reasonably possible. However, publicly reported wealth and donation figures can be incomplete, estimated, disputed, or later revised. NoCharity is not affiliated with, sponsored by, or endorsed by the people, organizations, publications, or sources referenced. These calculations are strictly for entertainment and informational context—not financial, investment, legal, tax, or charitable advice.

Free MCP Architecture & Deployment

How this application runs for $0 on the internet

1. The Zero-Cost MCP News Engine

This app implements a standard Model Context Protocol (MCP) server in mcp-server.js that queries Google News RSS feeds with timeframe syntax (when:1y, when:30d, custom date ranges). It requires zero API keys and costs $0.

2. Free Deployment to Render

You can deploy this directly from your GitHub repo (iarnold5/nocharity) to a free Render Web Service. Render runs npm install and npm start automatically at $0/month.

3. Traceable Net Worth & Direct Source Links

Every net worth figure links directly to its source (Bloomberg Billionaires Index / Forbes Real-Time), and every donation links directly to published reports in AP News, Reuters, WSJ, and the Chronicle of Philanthropy.
